Tutorial / ट्यूटोरियल

1. Login securely with your credentials.
2. Go to Token Management to add tokens (TXT or manual).
3. Set Duration, Server ID & Channel ID in Setup.
4. Choose Key Mode (Manually, Owner Key, Client Key).
5. Start automation engine. OwO commands & hourly sell all run automatically!

1. अपने क्रेडेंशियल्स से लॉगिन करें।

3. सेटअप में ड्यूरेशन, सर्वर और चैनल आईडी सेट करें।
4. की मोड चुनें।
5. बॉट स्टार्ट करें, OwO कमांड्स और सेल ऑल ऑटोमैटिक चलेंगे!
